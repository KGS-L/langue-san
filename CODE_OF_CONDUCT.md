# Code de conduite

Langue SAN est un projet communautaire. Nous voulons un espace de collaboration respectueux pour les locuteurs, contributeurs techniques, chercheurs et partenaires.

## Comportements attendus

Nous demandons à chaque participant de :

- respecter les personnes et les communautés ;
- accepter que des variantes linguistiques puissent coexister ;
- distinguer désaccord linguistique et attaque personnelle ;
- expliquer les corrections avec bienveillance ;
- respecter le consentement, la confidentialité et les droits sur les données ;
- créditer correctement les sources et contributions lorsque cela est possible ;
- signaler les erreurs sans chercher à humilier un contributeur.

## Comportements inacceptables

Ne sont pas acceptés :

- insultes, harcèlement ou intimidation ;
- discrimination ;
- publication de données personnelles sans autorisation ;
- appropriation volontaire du travail d'autrui ;
- publication d'audios ou ressources protégées sans droit clair ;
- falsification ou invention volontaire de données linguistiques présentées comme validées.

## Désaccords linguistiques

Une divergence entre deux locuteurs n'implique pas nécessairement qu'une personne a tort. Elle peut révéler une variante, un contexte différent, une différence générationnelle ou une variété distincte.

En cas de désaccord, documentez :

- la forme proposée ;
- la variété ;
- la localité ou le contexte si pertinent ;
- le sens ;
- les validations disponibles.

## Application

Les mainteneurs peuvent modifier, masquer ou retirer les contributions qui ne respectent pas ces règles et limiter la participation d'un compte en cas d'abus répétés ou graves.
