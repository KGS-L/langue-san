# Data

Ce dossier ne contient pas les données brutes privées collectées auprès des contributeurs.

Il sert à publier :

- les schémas de données ;
- des exemples fictifs ;
- de la documentation ;
- éventuellement, plus tard, des datasets dont la publication a été explicitement autorisée.

## À ne pas commiter

```text
data/raw/
data/private/
audios personnels
exports non anonymisés
ressources tierces sans licence claire
```

## Dataset public futur

Toute version publique devra préciser au minimum :

- variété(s) couverte(s) ;
- méthode de collecte ;
- méthode de validation ;
- nombre d'entrées ;
- domaines couverts ;
- licence ;
- limites connues ;
- informations de consentement applicables.
